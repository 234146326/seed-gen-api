## ✨ 项目简介

**漫剧生产工作台** 是一款面向动漫、短剧创作者及 AI 爱好者的高效生产力工具。本项目致力于打破技术壁垒，提供稳定、灵活且不卡脖子的开放请求工具与生图引擎。

###适用：
- 如果你是想批量生成漫画分镜，还是探索不受约束的 AI 视频创作，本工作台都能为你提供基础轻量集成化 AI 应用能力。开放版可以扩展二次开发。（商用署名即可）

###不适用：
- 你想直接用于生产。本项目开放版当前版本限于特定场景提效和针对向往自由的重度使用者。商业化用途建议使用商业版。

---

## 🚀 核心功能

- **🎨 开放生图引擎**：支持高度自定义与开放请求，摆脱单一平台限制，高效产出高质量漫画分镜。
- **💬 文本模型提示词生成扩展**：已深度扩展对话交互模块，助力批量高效生图组件。
- **🎞️ 视频生成支持**：现已支持Minimax视频生成能力,自部署或外采算力配套每秒¥0.03-0.09。
- **⚡ 推荐（ 升级-商业版Seedance、开放版不提供）**：作者平常心推荐配合 **火山引擎 Seedance 模型** 进行生成（参考速度：最低 1.1/s/fast），性能表现卓越。
